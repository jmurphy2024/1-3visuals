📊 The 1/3 Country Project: Phase 2 Working Directory README
Last Updated: September 12, 2025

1. Project Overview
This repository contains the R scripts, data, and documentation for Phase 2 of the "1/3 Country Project." This initiative moves beyond national averages to analyze socioeconomic disparities in the U.S. by reimagining the population as three distinct income-based "countries": the Bottom Third, Middle Third, and Top Third.

The core goal is to develop a robust, reusable system for analyzing and visualizing socioeconomic data, ultimately informing more equitable and impactful science, technology, and innovation policy aimed at addressing complex societal challenges ("wicked problems").

---

2. Phase 2 Objectives
Phase 2 focuses on building out the analytical framework and infrastructure:

- Geographic Income Database Construction (Stage I): Create a comprehensive, high-quality reference database (geographic_income_database.rds) containing estimated median household income data for various U.S. geographic levels. This stage now includes a multi-step process for acquiring and harmonizing geographic data:
	-- I-A & I-B: Download NHGIS summary data and IPUMS microdata.
	-- I-C: Calculate PUMA-level income statistics.
	-- I-D: Acquire multiple vintages of TIGER/Line shapefiles (2021 & 2022) to align with pre- and 	post-2020 Census geographies, create a crosswalk between them, and perform spatial joins to 	accurately assign PUMA codes.

- Modular R-based Framework Development (Stage II & III): Refactor existing analysis scripts into a streamlined, reusable R framework. This involves:
	-- Creating shared R functions (shared_visuals.R, income_utils.R) for core logic.
	-- Designing standardized data preparation templates (template_data_prep.R) to simplify the 	process of integrating and visualizing new datasets.

### 7. R Script Formatting Guidelines 📝

To maintain consistency and readability across all R scripts in this project, adhere to the following formatting standards:

1.  **Script Header:**
    Every R script must begin with a comprehensive header block providing essential metadata. This header will be formatted with `##` for each line.

    ```R
    ## WD location: Where in the WD the script is located
    ## Script: your-script-name.R
    ## Purpose: A concise description of what the script accomplishes.
    ## Author: Your Name/Team Name
    ## Date Created: YYYY-MM-DD
    ## Last Modified: YYYY-MM-DD (Brief note on changes, if applicable)
    ## Dependencies: List of R packages required (e.g., readr, dplyr, ggplot2)
    ## Input: Path(s) to primary input data files.
    ## Output: Path(s) to primary output files generated by the script.
    ```

2.  **Hierarchical Sectioning:**
    Organize the script content into clearly defined, hierarchical sections using decimal notation and increasing equal signs, similar to the Phase 1 scripts. Each heading should concisely describe the subsequent code's purpose.

    * **Level 0: ABOUT (Special Case)**
        The very first section, providing the script header and initial setup details, should be `0. ABOUT`. It will not have preceding empty rows.
        ```R
        # ==== 0. ABOUT ====
        ## Script: data-clean-initial.R
        ## Purpose: Initial cleaning and preparation of raw data for exploratory analysis.
        ## Author: Your Name
        ## Date Created: 2025-08-18
        ## Last Modified: 2025-08-18
        ## Dependencies: readr, dplyr
        ## Input: 01_data/raw/source_data.csv
        ## Output: 01_data/processed/cleaned_data.RData

        # Load necessary libraries
        library(readr)
        library(dplyr)
        # ... other setup code ...
        ```
    * **Level 1 Heading:**
        These are major sections, **all caps**, preceded by **two empty lines** (after Level 0), and marked by **four equal signs (`====`)**. These act as main sections in RStudio's document outline.
        ```R


        # ==== 1. DATA LOADING AND INITIAL CLEANING ====
        ```
    * **Level 2 Heading:**
        Subsections, marked by **five equal signs (`=====`)**.
        ```R


        # ===== 1.1. Load Raw Data =====
        ```
    * **Level 3 Heading:**
        Further subdivisions, marked by **six equal signs (`======`)**.
        ```R


        # ====== 1.1.1. Read CSV Files ======
        ```
    * **Level 4 Heading (and so on):**
        Continue adding an additional equal sign for each deeper level of heading as needed.
        ```R


        # ======= 1.1.1.1. Filter for Relevant Columns =======
        ```

### 8. Key Project Documents & Chat Initiation 📁

All core project documents, including the comprehensive overview for initiating a new Gemini chat, are stored in a dedicated folder within the Working Directory. This ensures all essential context is readily available.
