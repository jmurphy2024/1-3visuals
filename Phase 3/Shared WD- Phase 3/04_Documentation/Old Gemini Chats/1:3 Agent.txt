## 📝 **R Script Formatting Guidelines**

To maintain consistency and readability across all R scripts in this project, adhere to the following formatting standards:

1.  **Script Header:**
    Every R script must begin with a comprehensive header block providing essential metadata. This header will be formatted with `##` for each line.
    ```R
    ## WD location: Where in the WD the script is located
    ## Script: your-script-name.R
    ## Purpose: A concise description of what the script accomplishes.
    ## Author: Your Name/Team Name
    ## Date Created: YYYY-MM-DD
    ## Last Modified: YYYY-MM-DD (Brief note on changes, if applicable)
    ## Dependencies: List of R packages required (e.g., readr, dplyr, ggplot2)
    ## Input: Path(s) to primary input data files.
    ## Output: Path(s) to primary output files generated by the script.
    ```

2.  **Hierarchical Sectioning:**
    Organize the script content into clearly defined, hierarchical sections using decimal notation and increasing equal signs. Each heading should concisely describe the subsequent code's purpose.

    * **Level 0: ABOUT (Special Case)**
        The very first section, providing the script header and initial setup details, should be `0. ABOUT`. It will not have preceding empty rows.
        ```R
        # ==== 0. ABOUT ====
    	## WD location: 02_Scripts/Data_prep
        ## Script: data-clean-initial.R
        ## Purpose: Initial cleaning and preparation of raw data for exploratory analysis.
        # ... full header content ...

        # Load necessary libraries
        library(readr)
        library(dplyr)
        # ... other setup code ...
        ```
    * **Level 1 Heading:**
        Major sections, all caps, preceded by two empty lines (after Level 0), and marked by four equal signs (`====`).
        ```R


        # ==== 1. DATA LOADING AND INITIAL CLEANING ====
        ```
    * **Level 2 Heading:** Subsections, marked by five equal signs (`=====`).
        ```R


        # ===== 1.1. Load Raw Data =====
        ```
    * **Level 3 Heading:** Further subdivisions, marked by six equal signs (`======`).
        ```R


        # ====== 1.1.1. Read CSV Files ======
        ```
    * **Level 4 Heading (and so on):** Continue adding an additional equal sign for each deeper level of heading as needed.

3.  **Code Comments:**
    In addition to headers, use ample inline comments (`#`) to explain complex logic, choices, and non-obvious steps within the code blocks.

## 📊 1/3 Country Project: Comprehensive Overview (Updated for Phase 3)

This document provides a comprehensive introduction to the "1/3 Country Project," outlining its core concept, outcomes of Phase 1 and 2, and the current strategic direction for **Phase 3: Narrative Development**.

#### Project Name: **1/3 Country Project**

#### Overall Vision:
The "1/3 Country Project" transcends traditional national average analyses to provide a granular understanding of socioeconomic disparities within the United States. It reimagines the U.S. population as **three distinct "countries"** based on household income: the **Bottom Third (Low-Income)**, **Middle Third (Medium-Income)**, and **Top Third (High-Income)**. The purpose is to reveal the differential impacts of economic and social systems on these groups to inform more equitable, targeted, and impactful science, technology, and innovation policy.

#### Phase 1 & 2 Summary: Foundational Framework
* **Concept Operationalization (Phase 1):** The three "countries" were defined using weighted household income: **Bottom Third** (approx. $0 to $64,400), **Middle Third** (approx. $64,401 to $130,000), and **Top Third** (approx. $130,001 and above). Analysis was conducted across 60 granular income quantiles (ventiles) and three societal domains: Economic Security, Health/Human Development, and Equity/Sustainability/Community Resilience. Outputs included the "1/3 Country Reader" and "Indicators Across Incomes Presentation."
* **Framework Development (Phase 2):** The project transitioned to building a **robust, reusable system**.
    * **Deliverable 1:** A clean, high-quality `geographic_income_database.rds` was constructed, providing demographic and estimated median household income for a wide range of U.S. geographic levels (e.g., county, tract, PUMA). This involved advanced income estimation for missing values using PUMA-level lookups.
    * **Deliverable 2:** A modular R-based framework was established by refactoring core logic into reusable R scripts: `shared_visuals.R` (for visualization functions like `create_final_plot()`) and `income_utils.R` (for utility functions like `add_income_estimates()`).
    * **Deliverable 3:** A "plug-and-play" standardized template (`template_data_prep.R`) was created to streamline the addition of new indicator data.

#### Phase 3: Building a Comprehensive Thematic Narrative

**Project Objective:**
Phase 3 shifts the focus from building the analytical framework to developing a comprehensive, multi-dimensional narrative that synthesizes the data to define the **lived experience** of citizens in each of the three income-based "countries."

**Key Objectives & Methodology:**

1.  **Thematic Framework Development:** Define the experience of each country across **five core thematic areas**: **Income/Wealth**, **Health**, **Education**, **Crime**, and **Quality of Life**. This includes establishing a **Guiding Philosophy** for each country.
2.  **Storytelling Framework:** Develop **Guiding Questions** for each theme (e.g., "What financial fear keeps people up at night?" for Income/Wealth, or "What is school for?" for Education) to anchor the narrative and ensure comparative consistency.
3.  **Metric Identification:** Select **5-6 key data metrics** for each theme that best describe and quantify the qualitative narrative being constructed.
4.  **Narrative & Visual Storytelling Synthesis:** Create the final deliverables:
    * **Thematic Narrative Chapters:** Cohesive, compelling narrative sections (approx. 5 pages per theme) that integrate the selected data points and address the Guiding Questions.
    * **Narrative Tables (Appendix A):** Concise thematic narrative tables (1-2 sentence summaries per metric/country).
    * **Visual Integration:** Seamlessly weave all accompanying data visualizations into the narrative to maximize storytelling impact.
